# Expense Tracker

## Overview

Expense Tracker is a Full-Stack Web Application that helps users manage their monthly income and daily expenses.

Users can:

- Create an account
- Login securely
- Store monthly salary
- Add expenses by category
- View total expenses
- Track balance amount
- Generate monthly reports

---
